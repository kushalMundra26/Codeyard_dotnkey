# DECISIONS

Running log of choices made while building SignalStudio (newest last).

1. **Python 3.12 via `uv`** — system Python is 3.9; `uv venv --python 3.12` gives a reproducible env. `mcp` needs ≥3.10.
2. **ffmpeg from `imageio-ffmpeg`** — no Homebrew on the build machine; the pip wheel ships a static ffmpeg 9.0 with `zoompan`, `xfade`, `drawtext`. `packages.txt` still lists `ffmpeg` for Streamlit Cloud; `video.ffmpeg_exe()` prefers a system ffmpeg.
3. **Rivals (10)** — every domain verified to serve `/products.json` on 2026-11-21: Minimalist, Foxtale, Deconstruct, The Derma Co, Plum, Re'equil, Pilgrim, Aqualogica, Dr. Sheth's, Fixderma. Mamaearth and Earth Rhythm also work but were left out to keep the brief's "10 rivals".
4. **Review sources (all 11 brands have one)** — discovered from each store's own product page and verified with real calls (see `docs/review_endpoints.md`): Judge.me (8 stores, JSON or HTML mode), Yotpo (Minimalist), Nector (Re'equil), Fera via a Next.js server action (Foxtale — fragile: the action id changes on redeploy). Judge.me pages cap at 33; we page desc then asc and dedupe by uuid.
5. **Rate limits are respected, never evaded** — Shopify returned `429 local_rate_limited` after a burst. `core/http.py` paces per host (≥1.5–3 s), backs off on 429/5xx honouring `Retry-After`, and gives up rather than switching transports. `scripts/collect.py` retries missing stores in later rounds (default 10 min apart).
6. **One analysis LLM** — `core/llm.py`: Anthropic Claude (default `claude-opus-5-5`, structured outputs via `client.messages.parse(output_format=<pydantic>)`, JSON-retry fallback) or Gemini REST if only `GEMINI_API_KEY` exists (docs flag `gemini-2.5-flash` as deprecated → default `gemini-3.5-flash-lite`). `LLM_MODEL_BULK` lets you put bulk review labelling on `claude-haiku-5-5` to cut cost. Every call is cached by hash and logged to `data/cost_log.jsonl`.
7. **Deterministic fallbacks, clearly labelled** — with no LLM key the app still runs end to end: lexicon labeller (English + Hinglish negation rules), rule-based specs, metric-templated SWOT/brief/copy. The UI always shows the engine (`llm` / `lexicon` / `template` / `rules`). Numbers always come from pandas.
8. **Quotes are verified** — an LLM label survives only if its quote is an exact (case-insensitive) substring of the review.
9. **Evidence ids** — `r:<brand>:<review_uuid>`, `m:<metric>` (pandas metrics), `m:net:<brand>:<topic>|<handle>` (product-level), `p:<brand>:<handle>`. `evidence.validate()` drops any SWOT point / ad / A+ module without ≥1 resolvable id.
10. **Claims checker = rules gate + evidence** — blocks medical/absolute words, banned brand words, SPF/PA mismatches, competitor names (ASCI), and any topic claim where D&K's own net sentiment is < 0 (n ≥ 3); warns on superlatives and mixed topics (net < 0.3). A blocked ad variant is never rendered.
11. **Images never draw the product or text** — background scene only (Higgsfield Soul → Cloudflare FLUX schnell → Pollinations → deterministic Pillow template). The real Shopify packshot is cut out (border flood-fill) and composited; all text is laid out in code with Fraunces / Plus Jakarta Sans / Noto Devanagari / Noto Bengali / Noto Tamil (OFL, from google/fonts).
12. **Pollinations** — the new `gen.pollinations.ai` needs an `sk_` key; without one we use the classic keyless endpoint and enforce ≥46 s between calls (docs: one at a time, ≥45 s).
13. **Sarvam** — translate: `mayura:v1`, `modern-colloquial`; TTS: `bulbul:v3` (v2 is gone), field names `text` + `language_code`, speaker `priya` (confirmed in the v3 speaker list). Subtitles are burned into frames with Pillow (no libass dependency).
14. **Higgsfield** — image-to-video on `kling-video/v2.5-turbo/standard` ($0.042/s → $0.21 per 5 s), auth `Authorization: Key id:secret`, our 9:16 ad uploaded via `/files/generate-upload-url`. Guarded by `HIGGSFIELD_MAX_USD`, a confirm checkbox and a button — never automatic. Seedance/Kling 3 paths could not be verified, so not used.
15. **Forecast** — no sales data is public, so the "sales opportunity forecast" is review velocity per brand (a demand proxy) with a linear 3-month projection, labelled *estimate*. Opportunity score is also labelled *estimate*.
16. **Launch trends use `created_at`** — `published_at` resets on republish; still labelled approximate.
17. **Radar** — a real diff needs two dated snapshots; until the second daily snapshot exists, the radar shows the baseline date plus launches by `created_at` (last 45 days). Nothing is simulated.
18. **n8n** — uses only Schedule Trigger, Webhook, HTTP Request, IF and Wait nodes. Telegram calls go through HTTP Request to the Bot API so the inline Approve/Reject buttons can carry `$execution.resumeUrl?decision=…` without credential-shape issues. Older, stable typeVersions are used (httpRequest 4.2, if 2, webhook 2, wait 1.1, scheduleTrigger 1.2) for broad import compatibility. Needs `N8N_BLOCK_ENV_ACCESS_IN_NODE=false` for `$env.*`.
19. **MCP** — `mcp` 2.x renamed `FastMCP` → `MCPServer` (`mcp.server.mcpserver`); `mcp_server.py` uses the new name.
20. **Category filter** — single SKUs only (packs/combos/kits excluded so ₹/ml compares like with like); lip products with SPF belong to `lip_balm`, not `sunscreen`.
